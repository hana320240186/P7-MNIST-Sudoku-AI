# P7 Sudoku AI Lab — Google Colab + Streamlit

نسخة تعليمية مبسطة: CNN يتدرّب على صور MNIST الحقيقية، وواجهة Streamlit تعرض شبكة السودوكو قبل وبعد التصحيح وتقارن UCS وGreedy وA*.

## ما الذي يتدرّب على بيانات حقيقية؟
- `train_mnist.py` ينزّل MNIST الحقيقي باستخدام `tensorflow.keras.datasets.mnist`.
- يقسم الـ 60,000 صورة الأصلية إلى 50,000 تدريب و10,000 تحقق أولاً.
- يحذف الرقم 0 بعد التقسيم لأن المشروع يتعامل مع الأرقام 1 إلى 9.
- يحتفظ بمجموعة اختبار MNIST الأصلية (10,000 صورة) ولا يستخدمها في التدريب، ثم يحذف منها الصفر للتقييم.
- يحفظ النموذج في `models/mnist_digit_model.keras` والنتائج في `results/`.

## تشغيل سريع في Google Colab
1. ارفعي ملف ZIP إلى Google Drive أو حمّليه على جهازك.
2. فكّي ضغط الملف على جهازك، ثم ارفعي ملف `P7_MNIST_Colab_Studio.ipynb` إلى Google Colab وافتحيه. (أو استخدمي رابط الـ Notebook المنفصل المرفق.)
3. شغّلي الخلايا بالترتيب. أول خلية تطلب منك رفع ملف ZIP للمشروع من جهازك.
4. اختاري Runtime → Change runtime type → T4 GPU (اختياري لكنه أسرع).
5. التدريب يحتاج إنترنت لتنزيل MNIST، وقد يستغرق عدة دقائق حسب الـ GPU.
6. خلية تشغيل Streamlit تطلب Ngrok Auth Token. أنشئي حساباً مجانياً في https://ngrok.com/ وانسخي الـ token. لا تضعيه داخل الكود أو تشاركيه مع أحد.

## تشغيل محلياً في VS Code
```bash
pip install -r requirements.txt
python train_mnist.py
streamlit run app.py
```

## ماذا تعرض الواجهة؟
- حالة تدريب MNIST، دقة الاختبار، وأعداد صور التدريب والتحقق والاختبار.
- مصفوفة الالتباس للأرقام 1–9.
- اختبار صورة رقم واحدة باستخدام النموذج المدرب.
- لغز مولّد قابل لإعادة الإنتاج أو إدخال شبكة يدوياً.
- BEFORE: الشبكة قبل التصحيح وعدد الخلايا الفارغة والتعارضات.
- AFTER: الشبكة المصححة، الحل النهائي، سجل التعديلات والتكلفة.
- مقارنة UCS وGreedy وA* بعدد العقد والزمن والتعديلات.

## ملاحظة علمية مهمة
الواجهة في هذه النسخة تصنّف صورة رقم مفردة باستخدام CNN، لكنها لا تستخرج شبكة 9×9 كاملة تلقائياً من صورة سودوكو. وضع المثال المولّد يحقن أخطاء معروفة كي نختبر Search وCSP بوضوح؛ احتمالات هذا المثال توضيحية وليست تنبؤات CNN. لا نعرض هذه الاحتمالات على أنها خرج النموذج الحقيقي.

## الملفات
- `train_mnist.py`: تنزيل MNIST وتدريب CNN وتقييمها.
- `app.py`: واجهة Streamlit.
- `p7/sudoku.py`: تعارضات السودوكو وBacktracking وتوليد مثال.
- `p7/search.py`: UCS وGreedy وA* لتصحيح الخلايا المتعارضة.
- `P7_MNIST_Colab_Studio.ipynb`: خطوات التشغيل على Colab.
